IMDb Air Date Fixer

Sets Date added to the air/release date, so Recently Added is ordered by when something was released, not by when the file was created. Episodes missing an air date or title are looked up via the series' IMDb/TVDb ID (TVmaze and, optionally, OMDb/IMDb). If nothing is found, the date is estimated from the series' other episodes, and items with no date at all get an older year so they never show up first.

Master switch. Turned off automatically when you run the "restore original 'Date added'" task.

Applies to

Mixed content / home video libraries (e.g. documentaries without movie metadata). Extras are never touched.

Missing metadata (IMDb)

Matches the series' IMDb/TVDb ID on TVmaze (free, no key). Series without IDs are matched by name + year, and the IDs are saved on the series.
IMDb data via omdbapi.com (free key, 1,000 lookups/day). Used when TVmaze has no date, and to fill in episode IMDb IDs.
Air date, title (only if the current title looks like a file name), overview (only if empty) and IMDb ID. Locked fields are never changed.
Nearest episode in the same season, the season premiere, the end date of ended series, or the release year for movies.
January 1st of the item's own year or the series' start year, so they never show up first. Corrected automatically once real metadata appears.
Used when an undated item has no year at all.

Behavior

Otherwise only when the scheduled task runs (every night at 04:00 by default).
Release date + time of day, so episodes released on the same day stay in download order.
So sorting by "Date episode added" in TV libraries follows the episodes' air dates.
Items where "Lock this item" is checked in the metadata editor are left alone.
Only relevant if NFO saving is enabled for the library. Updates <dateadded> in the NFO too.
Run the task and check the server log to see what would change.

After a run, a report of items that could not be matched is written to plugins/configurations/Jellyfin.Plugin.ReleaseDateAdded.report.txt (and summarized in the server log). Original dates are backed up. To undo everything, run "IMDb Air Date Fixer: restore original 'Date added'" under Dashboard → Scheduled Tasks.
