Air Date and Metadata Fixer

Sätter Date added till sändnings-/releasedatum så att Recently Added sorteras efter när något släpptes, inte efter när filen skapades. Avsnitt som saknar datum eller titel slås upp via seriens IMDb-/TVDb-ID (TVmaze och valfritt OMDb). Går inget att hitta uppskattas datumet från seriens övriga avsnitt.

Huvudbrytare. Stängs av automatiskt om du kör uppgiften "Återställ ursprungliga 'Date added'".

Gäller

Bibliotek med blandat innehåll/hemvideor (t.ex. dokumentärer utan filmmetadata). Extramaterial rörs aldrig.

Saknad metadata (IMDb / TVmaze)

Matchar seriens IMDb-/TVDb-ID mot TVmaze (gratis, ingen nyckel). Saknar serien ID används namn + år, och ID:na sparas på serien.
IMDb-data via omdbapi.com (gratis nyckel, 1000 uppslag/dag). Används när TVmaze saknar datum och för att fylla i avsnittens IMDb-ID.
Sändningsdatum, titel (bara om titeln ser ut som ett filnamn), beskrivning (bara om den saknas) och IMDb-ID. Låsta fält rörs inte.
Närmaste avsnitt i samma säsong, säsongens premiär, avslutade seriers slutdatum, eller utgivningsåret för filmer. Gör att gamla serier utan metadata inte hamnar först.

Beteende

Annars sker det bara när den schemalagda uppgiften körs (varje natt kl 04:00 som standard).
Releasedatum + klockslag. Avsnitt som släpps samma dag hamnar då i den ordning de laddades ner.
Så att sortering på "Date episode added" i TV-biblioteket följer avsnittens releasedatum.
Objekt där du kryssat i "Lås detta objekt" i metadata-redigeraren rörs inte.
Bara relevant om du har NFO-sparning påslaget i biblioteket. Gör att <dateadded> i NFO också uppdateras.
Kör uppgiften och kolla serverloggen för att se vad som skulle ändras.

Efter körning finns en rapport över avsnitt som inte gick att matcha i plugins/configurations/Jellyfin.Plugin.ReleaseDateAdded.report.txt (och i serverloggen). Ursprungliga datum sparas i en backup. Vill du ångra allt: kör "Air Date Fixer: återställ ursprungliga 'Date added'" under Dashboard → Schemalagda uppgifter.
